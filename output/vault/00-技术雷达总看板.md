# 全球技术雷达与权威讲座总看板

> [!TIP]
> 本看板由 **TechRadar Pipeline** 自动化维护，原生兼容 **Obsidian Dataview** 插件。
> 每天自动扫描全球权威大会 (QCon, USENIX)、顶尖播客 (Dwarkesh, Latent Space) 与知名科技大厂工程博客。

---

## 1. 最新研读流 (Live Feed)

```dataview
TABLE 
  author AS "讲师 / 作者", 
  platform AS "来源平台", 
  type AS "模式", 
  date AS "研读日期"
FROM #学习笔记/深度研读 OR #学习笔记/原貌切片
SORT file.mtime DESC
LIMIT 20
```

---

## 2. 顶级技术会议与讲座 (Conferences)

```dataview
TABLE 
  author AS "大会/讲师", 
  platform AS "平台", 
  date AS "时间"
FROM #领域/conference
SORT date DESC
```

---

## 3. 科技大厂工程演进专栏 (Engineering Blogs)

```dataview
TABLE 
  author AS "公司/团队", 
  date AS "发布日期"
FROM #领域/blog
SORT date DESC
```
